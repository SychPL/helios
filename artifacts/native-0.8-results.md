# Helios 0.8.0 - Music Assistant (etap 2 planu)

- Spec: docs/SPEC-0.6-music-assistant.md; plan: docs/PLAN-0.6-0.7-implementation.md (T2.1-T2.6). Kontrakt API MA odczytany z żywej instalacji 2.10.3: docs/ma-api-2.10.3.md.
- `SendspinClient` (własny klient legacy v1 na Java-WebSocket, bez nowych zależności): hello z rolami player/metadata/artwork/controller i PCM 48 kHz, `ClockOffset` (najmniejsze RTT z ostatnich 8), kolejka po znacznikach czasu z odrzucaniem spóźnionych (>50 ms) i wyprzedzeniem 200 ms, `stream/clear` = flush, `stream/end` = drain z kontynuacją przy `stream/start` tego samego formatu, `server/command` volume/mute potwierdzane `client/state`, okładka ≤ 1 MiB, reconnect bez autoplay, `client/goodbye` przy stopie. `AudioTrackSink`: `AudioTrack` MODE_STREAM, USAGE_MEDIA, bufor 500 ms, `getUnderrunCount()` do bramki.
- `MusicAssistantClient`: `auth` pierwsze, `message_id`, tory (search zastępuje, players/play/cmd blokują, stop nigdy), timeout 10 s, `imageproxy` tylko na hoście MA, zapytanie 2-100 znaków, `providers=["library"]`.
- `MusicSession`: transient loss → pauza lokalna, wznowienie tylko po przyznanym focusie; ducking; trwała utrata (Cast) → `pause` przez transport, bez samoczynnego wznowienia; po `ready` z Assist nowe żądanie focusu.
- `HeliosService`: start klientów z sekcji `music_assistant`, `reconfigure` niezależnie per sekcja HA/MA (probe przed zapisem), `player_id` Lenovo z `players/all` (provider `sendspin`, nazwa gracza), zdalne granie na kafelku, głośność/mute nakładki przez API MA do `player_id` Lenovo, transport przez `client/command` gdy serwer go wspiera, inaczej API.
- UI: `MusicOverlay` (uchwyt `♪` 72x72 przy prawej krawędzi w połowie wysokości, panel prawej połowy: okładka, tytuł, wykonawca, ◀◀ ▶/❚❚ ▶▶ ■, głośność, Wycisz, Schowaj; dotyk nie dociera do kafli; kafle nie są przebudowywane, nakładka `bringToFront` po każdym `setSpec`), `MusicLibraryDialog` (wybór gracza, wyszukiwanie, ostatnie 10, wyniki utwór/album/playlista/radio, sterowanie wybranym graczem), schemat `version: 3` z jednym opcjonalnym kafelkiem `music`, ikona `music`, kafelek obsługiwany przed bramką `live`.
